## Servers

### CannaAnarchy

Raw, persistent Minecraft survival. No claims, no planned resets, and no hand-holding — just the history players leave behind.

### CannaSMP

A community survival server with custom systems, events, economy, crates, and progression.

## About this repository

This repository is served through GitHub Pages. It contains the public site, vote page, and live Anarchy status page.

The Anarchy status snapshot is refreshed by GitHub Actions. The public JSON endpoint is available at [`/api/status.json`](https://cannanetwork.github.io/api/status.json).
